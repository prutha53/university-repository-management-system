# UniRepo — University Repository Management System

A secure, centralized platform for managing university documents with role-based and hierarchy-based access control.

## Features

- 🔐 JWT authentication
- 👥 Role & hierarchy-based access
- 📁 Structured folder management
- 📄 Document upload, view & download
- 🛡️ Owner-only deletion
- 🔎 Search & filtering
- 📊 Audit logging

## Tech Stack

React • Node.js • Express • PostgreSQL
