# UniRepo Frontend

React + Vite frontend for the University Repository Management System (PS-1).

## Run

```powershell
npm install
npm run dev
```

The frontend defaults to `http://localhost:5000` for the backend. To change it, create `.env`:

```text
VITE_API_URL=http://localhost:5000
```
